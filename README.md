# Infocasas Uruguay 物件データセットサンプル

<h2>21,859件のレコードを含むサンプルデータセット</h2>

この**Infocasas Uruguay Properties Dataset Sample**には**21,859件のレコード**が含まれており、**Bright Data API**を使用して抽出されました。

## データポイント

| Field Name | Description |
|------------|-------------|
| `URL` | 物件掲載ページのWebアドレス。 |
| `ID` | 各物件掲載の一意の識別子。 |
| `Imagen` | 掲載されている物件画像へのリンク。 |
| `Descripcion` | 特徴や設備を含む物件の簡潔な説明。 |
| `Precio` | 現地通貨で表示された掲載価格。 |
| `Ubicacion` | エリアや通りを含む物件の所在地詳細。 |
| `Habitaciones` | 物件のベッドルーム数。 |
| `Banos` | 物件のバスルーム数。 |
| `Dimension_propiedad` | 平方メートル単位での物件の総面積。 |
| `Dimension_terreno` | 平方メートル単位での土地面積。 |
| `Titulo` | 物件掲載のタイトル。 |
| `Phone1` | 物件掲載の主な連絡先電話番号。 |
| `Phone2` | 物件掲載の副連絡先電話番号。 |
| `Email` | 物件に関する問い合わせ用メールアドレス。 |
| `Seller` | 売主または不動産エージェントの名前。 |
| `Tipo_de_vendedor` | 売主の種類（例：エージェントまたはオーナー）。 |
| `Estado` | 物件の現在の状態（例：販売中、売却済み）。 |
| `Nueva_usada` | 物件が新築か中古かを示します。 |
| `Type` | 物件の種類（例：アパート、戸建て）。 |
| `Venta_Arriendo` | 物件が売買用か賃貸用かを示します。 |
| `Region` | 物件が所在する地域。 |
| `Comuna_Ciudad` | 物件が所在する市またはコミューン。 |
| `Parqueaderos` | 物件に付随する駐車スペース数。 |
| `Year` | 物件が建築または掲載された年。 |
| `Destacado_Superdestacado` | 物件が注目物件またはハイライト表示されているかを示します。 |
| `url` | 物件掲載の代替URL。 |
| `seller_id` | 売主または不動産エージェントの一意の識別子。 |


## ユースケース

### 1. 不動産市場分析
このデータセットを活用して、ウルグアイのさまざまな地域における不動産市場トレンドを分析し、投資家や不動産業者のデータドリブンな意思決定を支援します。

### 2. 都市開発研究
研究者はこのデータセットを使用して、ウルグアイにおける都市拡大、住宅の手頃さ、人口動態が不動産に与える影響を研究できます。

### 3. 競争ビジネスインテリジェンス
企業はこのデータを活用して、競合の掲載情報、価格戦略、市場動向を把握し、自社の提供内容を最適化できます。
